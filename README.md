# NEON SURGE 180

## ゲームのタイトルと概要

**NEON SURGE 180** は、単一の HTML ファイル（[`index.html`](index.html)）だけで動作する、見下ろし全方位型の 3ステージ制サバイバー・シューティングゲームです。

大量に押し寄せる敵を倒して EXP ジェムとスコアを獲得し、レベルアップごとに提示される 3択スキルで自機を強化しながら、各ステージの撃破ノルマ達成で出現するボスを撃破していきます。全 3ステージの踏破を目指し、目標タイム 3分（03:00）以内のクリアで最高評価 **RANK S** を獲得できます。

### ステージ構成
- **STAGE 1（目標撃破: 45体）**: 基本の `Chaser` や高速な `Scout` などが中心。達成後にボス `SENTINEL ALPHA` が出現。
- **STAGE 2（目標撃破: 75体）**: 硬い `Tank` や遠距離攻撃を行う `Shooter` が本格参戦。達成後にボス `DREADNOUGHT BETA` が出現。
- **STAGE 3（目標撃破: 105体）**: 全種類の敵が押し寄せる最終決戦。達成後に最終ボス `OMEGA OVERLORD` が出現（HP 50% 以下で第2形態へ移行）。

## 遊び方（操作方法）

外部ライブラリやビルド環境は不要です。[`index.html`](index.html) をブラウザ（Chrome / Edge 等）でそのまま開くと遊べます。

### 操作一覧
| 入力 | 動作 |
| :--- | :--- |
| `W` `A` `S` `D` / `↑` `↓` `←` `→` | 自機の移動 |
| マウスカーソル | 狙う方向の指定（ショットは自動連射） |
| `Space` / 右クリック | **必殺ボム（ショックウェーブ）** の発動（敵弾消去＋周囲大ダメージ） |
| `Q` / 画面右上ボタン | **マウス照準 ⇔ オートエイム（最寄り敵自動狙い）** の切り替え |
| `1` `2` `3` / クリック | レベルアップ時のスキル・ステージクリア時のレジェンド強化を選択 |
| `P` / `Esc` | 一時停止（ポーズ） |

### ゲームの流れと成長要素
1. **敵を倒して EXP ジェムを回収**: 近づくとジェムを吸い寄せ、ゲージが溜まるとレベルアップします。
2. **スキル選択（全13種）**: 「マルチショット」「プラズマオーブ」「ホーミングミサイル」「サンダーボルト」「連鎖爆発」「プリズムレーザー」「ショックパルス」などから毎回 3択で強化します。**Lv.3 以上になると覚醒**し、見た目や攻撃範囲が強化されます。
3. **特殊ドロップ**: 雑魚敵から低確率で「全EXPマグネット」「連射フィーバー（8秒間 連射2倍＆移動速度UP）」「回復コア」がドロップします。
4. **STAGE CLEAR 報酬**: Stage 1・Stage 2 のボスを倒すと区切り画面になり、通常スキルとは別枠の **レジェンド強化（3択）** を獲得し、HP を回復して次のステージへ進みます。

## 工夫した点

- **外部アセットなしの単一 HTML 完結設計**
  - 画像や音声ファイルを一切使わず、HTML5 Canvas 2D と Web Audio API（ショット・撃破・爆発・レーザー・レベルアップ・ボス警告などのシンセ効果音）だけで完結させ、ファイルを開くだけで動作するようにしました。
- **大量の敵やエフェクトでも軽快に動く描画処理**
  - 負荷が高くなりやすい `shadowBlur` を避け、半透明の円を重ねる擬似グロー表現や、パーティクル・爆発オブジェクト数の上限管理を取り入れています。
- **爽快感と遊びやすさの両立**
  - Lv.3 以上のスキル覚醒によるエフェクト変化、ステージクリアごとの強力なレジェンド強化、画面を一掃できる必殺ボム、連続撃破によるコンボ倍率スコア、`localStorage` へのハイスコア・最速タイム保存を備えています。
  - ボスの突進やレーザー攻撃には事前の予告線を表示し、マウス照準とオートエイムをワンキー（`Q`）で切り替えられるようにして、シューティングが苦手な方でも遊びやすくしました。

## 作りながら変えた点

Git のコミット履歴（`67e2da7` → `44eaf03`）に沿って、初期実装から以下の点を改良しています。

1. **敵撃破アニメーションの爆発表現への刷新（`44eaf03`）**
   - 初版（`67e2da7`）では敵を倒した際に小粒のパーティクルが飛び散るだけでしたが、撃破時の手応えを強めるために、中心の白い閃光・膨張する爆炎・広がる衝撃リング・四散する破片を組み合わせた爆発アニメーション（`spawnEnemyExplosion`）へ変更しました。
2. **ボス撃破時の余韻演出と画面遷移の改善（`44eaf03`）**
   - 初版ではボス撃破と同時に即座にクリア／ステージクリア画面が開いてしまい爆発が見えにくかったため、ボス撃破後に約 `0.85` 秒の多段大爆発＆周囲の雑魚敵一掃タイム（`pendingOutcome`）を挟んでから画面遷移するように変更しました。
   - あわせて、爆発演出中に倒した敵やボスの攻撃予告線・ボス HP バーが画面に残らないよう描画条件と HUD 更新条件を整理しました。
3. **ポーズ画面・リザルト画面からのタイトル復帰対応（`44eaf03`）**
   - 初期版ではポーズ画面とゲームオーバー／リザルト画面に「もう一度プレイ（最初から）」しかありませんでしたが、遊び直しや開始オプション（オートエイム／ミュート）の切り替えを行いやすくするため、両画面に **「タイトルにもどる」** ボタン（`goToTitle`）を追加し、プレイ中に変更した設定もタイトル画面へ引き継ぐように改善しました。
